# CLAUDE.md

This repo is a **Game Boy Color game-making kit**: an agent skill, a toolchain and a
working example ROM. `@SKILL.md` is the full guide — read it before writing code.

## Working rules

- Start from `templates/minimal-gbc/` (a complete title → play → score → clear game in
  one C file). Copy it, then change it.
- Art is PNG first (`tools/png2gbc.py`, `tools/artfont.py`), C second, ROM third.
- Build with `./templates/minimal-gbc/build.sh` — it finds GBDK without `make`.
- **Always playtest and look at the frames** before saying anything works:
  `python3 tools/playtest.py --rom <rom> --script "..." --out strip.png`, then open the
  strip PNG. A compile is not a proof.
- Budgets: 384 tiles of VRAM shared by background and sprites, background tile indices
  ≤ 255, 40 sprites / 10 per scanline, 4 colours per tile.
- `src/gen/*` is generated by `assets/make_art.py`; never hand-edit it.
- CGB-only calls need `if (DEVICE_SUPPORTS_COLOR)`; `-Wm-yc` is the CGB-compatible ROM
  flag (`-Wm-yC` is CGB-only, they are not interchangeable).
- `GBDKDIR` must end in a slash when you call `lcc` yourself.

## Nice-to-know

- `tools/playtest.py` script grammar: `wait:N`, `press:BTN:N`, `hold:BTN:N`,
  `release:BTN`, `snap[:LABEL]`; buttons `up down left right a b start select`.
- To test a win condition quickly, build a smaller ROM with a smaller constant, e.g.
  `lcc -DSTAR_TOTAL=1 ...` gives a one-star game that clears in one move.
- Keep one screenshot strip in `docs/images/` and link it from the README.
