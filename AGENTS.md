# AGENTS.md

This repository is a **Game Boy Color game-making kit for coding agents**. It is not an
app; it is a skill, a toolchain and a working example ROM.

## Read first

Read [`SKILL.md`](SKILL.md) before writing any code. It holds the hardware limits, the
GBDK API cookbook and the build/playtest loop. Every rule below comes from it.

## The loop you must follow

1. **Art as PNG first** — `tools/png2gbc.py` (tiles + palettes), `tools/artfont.py` (text).
2. **C next** — start from `templates/minimal-gbc/src/main.c`, do not start from scratch.
3. **Build** — `./templates/minimal-gbc/build.sh` (or `make -C templates/minimal-gbc`).
4. **Playtest** — `python3 tools/playtest.py --rom <rom> --script "..." --out strip.png`.
5. **Look at the strip** — open the PNG and check it with your own eyes.
6. **Fix and repeat.**

A ROM that compiles is not a ROM that works. Never report a game as finished without a
playtest strip you have actually looked at.

## Hard rules

- **Tile budget:** 384 tiles in VRAM total (background + sprites share it), background
  tile indices 0–255. Keep a `#define` block that assigns each asset a base slot and a
  `#error` if the total overflows.
- **Art budget:** 4 colours per tile (3 + transparency for sprites). Art must be 8×8
  aligned if the ROM needs to change it at runtime.
- **Tile economy:** use `--dedup` on backgrounds and draw a small repeating tileset.
  A background where every cell is unique eats the entire VRAM.
- **Sprites:** 40 OAM entries, 10 per scanline; `move_sprite(n, x + 8, y + 16)`.
- **Frame:** `vsync()` at the top of the main loop; keep per-frame work small.
- **CGB registers** (`set_bkg_palette`, `VBK_REG`, `cpu_fast`) are CGB-only — guard with
  `DEVICE_SUPPORTS_COLOR`. `-Wm-yc` = CGB compatible, `-Wm-yC` = CGB only.
- **`GBDKDIR` needs a trailing slash.** `build.sh` handles it; a raw `lcc` call does not.

## Commands

```bash
./tools/check_env.sh                      # is GBDK / python / pyboy present?
./templates/minimal-gbc/build.sh          # build the example ROM
./templates/minimal-gbc/build.sh --assets # redraw art, convert, build
python3 tools/playtest.py --rom templates/minimal-gbc/build/tile-hop.gbc \
  --script "wait:40,press:start:4,wait:20,hold:right:40,snap:score" --out build/strip.png
```

## Do not

- Do not commit `build/` output, `*.o`, `*.ihx`, `*.map`, `*.lst`, `__pycache__`.
- Do not edit `src/gen/*` by hand — it is generated by `assets/make_art.py`.
- Do not add a dependency that needs a network connection at build time.
